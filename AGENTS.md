# AGENTS.md

Rules for every agent and human working on CORE BREACH: PIT. Read this first, every session.

## The project
- Retro-pixel **ranked** boss-rush arena, spinoff of Core-Breach: Zero. Static browser game: no build step, no backend, no accounts, no network calls.
- `engine.js` is a pure engine (no `document`, `window` or `localStorage` in `engine.js`, `chars.js`, `bosses.js`, `palette.js`). Bosses are data interpreted by the engine — never hardcode a boss's logic inside the engine.

## House rules
- **`npm test` must pass before every push to `main`.** It runs the PIT sim suite. Do not push broken code.
- **Fairness law:** every hostile action telegraphs >= 0.5s (the PHASE FURY tele compression may shorten a telegraph but never below this floor); projectile speed <= 90, charge speed <= 190; floor pools are outlined during telegraph and never spawn on the player; phase transitions wipe live hazards and then fire the gold burst ring (46 + 4/phase px/s — always slower than the player's run speed 68, no rank/phase multipliers on it). The tests enforce this — do not weaken them to make a pattern pass.
- **PHASE FURY (owner spec: "make boss phases actually do something"):** the engine's `AGGRO` curve escalates every phase — gap `[1, 0.92, 0.85, 0.78]`, projectile speed `[1, 1.06, 1.12, 1.16]`, tele compression `[1, 0.96, 0.92, 0.88]` — and every transition fires the burst ring. Enrage (final-phase flag) stacks on top: shots/charge/spiral ×1.15, gap ×0.78. Curve values are engine-side and global; boss data is tuned to sit UNDER the curve, never the other way round.
- **Roster calibration (owner spec, enforced by tests):** bronze band stays easy (max 300 base HP, 2 phases); the silver band IS the DEATHWARRANT area (480–560 base HP, 3 phases, SILVER preset pinned near ×1.05 HP with no pacing squeeze); the gold band sits strictly past the anchor and under 600 (3 phases: BRASS HERALD 525, THE AUDITOR 535, TOLLMASTER 545, THE LEDGER 555); the beyond band sits strictly above the silver band, ordered by base HP. DEATHWARRANT (520) is the untouched anchor — do not nerf it to make a gate pass.
- **Arena pool ownership (owner spec, enforced by tests):** each arena (rank) owns its boss pool EXCLUSIVELY — the seven pools are pairwise disjoint, their union is the whole 31-boss roster, every pool has >= 3 bosses (the five beyond/gold pools roll FOUR each since ROUND VARIETY), and pool max base HP escalates arena by arena. Never let two ranks roll the same boss.
- **ROUND VARIETY mutators (owner spec: "make each round sorta unique ... less tedious"):** the engine (`MUTATORS` + `rollMutators` in `engine.js`) draws house twists with every queue, deterministically per fight seed. Draw counts: BRONZE 55% for one (the warm-up stays mostly clean), SILVER always one, GOLD/PLATINUM usually two (65%), DIAMOND+ always two. Effects compose multiplicatively with the rank presets (hp/gap clamp widened to [0.4, 3.5] / [0.4, 1.5] to make room). Two hard laws, test-enforced: **mutators NEVER touch spawn counts or swarm caps** (summon-cadence law — BROOD BLIGHT only alters minion HP, and only joins the deck if the rank's pool owns a spawn-pattern boss), and **the tutorial must stay winnable 3/3 against every single mutator**. BOUNTY multiplies the SR delta (wins AND losses) via `applyRankedResult`'s `srMult` (default 1) — the payout stays integer-rounded. When you add a mutator: deck entry + effect pin + tutorial gate + README table row, all in the same commit.
- **Balance is gated three ways, by measured reality:**
  1. The dodge-bot (VOLT) must clear the bronze band at the BRONZE preset, the whole silver band at the SILVER preset, and the gold band at the GOLD preset, 3/3 fixed seeds, plus a flawless GATEKEEPER.
  2. The dodge-bot (BULWARK) must clear the beyond band at base (all sixteen bosses), 3/3 seeds. PLATINUM+ presets are the **documented beyond-bot wall** — humans outplay the bot there; the suite survival-gates them (bot must survive 40s+) instead of demanding full clears. ONE endability exception: GRAVEWAKE is win-gated at the PLATINUM preset (3/3) — the summon-stall regression pin (BROOD TAX 2026.11.13). Deaths are the wall's business; a boss the player survives but can never FINISH is a bug.
  3. The dashless casual reference (same bot brain, dash disabled) must clear the bronze tutorial on at least half its seeds and never clear the DEATHWARRANT area. HIVE MOTHER is knowingly kite-able without dash (spiral gaps) — logged as INFO, a design fact, not a balance leak.
  - If a boss fails its gate, fix the pattern, not the test. Harness-side exceptions so far: beam danger weight 10 (beams outrun the player; the counter is dashing THROUGH, the tutorial's own advice) and telegraph-cone reading + edge weight 1.1 (the bot once camped walls and ate volleys there — no human does). Pattern-side lessons learned the same way:
    - Dense shotgun volleys (5-shot 30° cones) hit the cone-reading bot once per phase — keep volleys at 4 shots / ≤26° (CARRION LAW geometry), or 2-shot fans when the fight runs long (VOLT attrition).
    - Herding pairs are the recurring killer: spawn/floor-pools/charges/rings combined with cone pressure steer the bot into the kill. Keep ONE pressure theme per phase (THE GLUTTON, GRAVEWAKE, TIDE UNBOUND, GLOAMWARDEN, TOLLMASTER all shipped wrong and went sub-3/3 until restructured).
    - Floor pools stack on the fury cycle: 4-5s lifetimes cast every ~1-2s leave 8+ live pools. Cap pool counts (≤3) and lifetimes (≤4.5s) in later phases.
    - PHASE FURY specifically: tele compression ×0.92 at phase 3 puts 0.6-0.65s cone telegraphs at the bot's cone-clear knife edge (~0.6s needed) — raise the DATA tele of affected patterns (e.g. 0.65 → 0.75) so the POST-compression value matches the pre-fury reaction time; do not flatten the curve.
    - **Summon cadence law (BROOD TAX 2026.11.13, owner report: GRAVEWAKE "just about unbeatable due to how often it summons"):** the round-robin picker fires a 2-pattern phase's spawn every 2nd cycle. At PLATINUM pacing that is ~0.58 minions/s — exactly the player's minion kill rate (0.55-0.66/s), so the swarm never empties, the gun is pinned on blob cleanup and boss DPS collapses to ~10%: the fight CANNOT end (measured: 244s brood phase, 70 spawn events, 140 kills, bot stalled at 19-50% for 300s while taking 0-1 hits). Law: spawner phases keep spawn at most 1-of-3 patterns with the swarm cap low (≤ 4-6); probe spawner phases with a stall-trace (boss damage/s per phase) before shipping — the stall signature is a phase running 100s+ under 25% of full boss DPS. A 2-pattern spawn phase only survives at short windows (silver HP): re-measure whenever the phase's HP window or rank pacing changes. The suite pins GRAVEWAKE@PLATINUM 3/3 + the data cadence (spawn 1-of-3, cap 4) as the regression.
- **ROUND ANNOUNCER (owner spec: "make the modifiers pop up right before the round starts ... count down from 5, say the boss name and the modifier(s) and what they do"):** every queue opens with `#ready-ov` — a `READY_SECS = 5` countdown in `app.js` naming the boss, its HP at this pacing, and each mutator with its blurb, then a short FIGHT beat. The sim stays FROZEN while it is up (loop returns before stepping, input gated, `P` still pauses), and `startFight` re-hides it among the overlay-hygiene pass. When you add mutator fields the announcer shows, keep the blurb human-readable — it is the only thing many players will read.
- **Display multipliers only through `fmtMul` (`engine.js`):** composed multipliers are float products; raw interpolation prints garbage like `1.0999000000099999`. `fmtMul` rounds to 3 decimals and prints the shortest clean string. Fight title, ladder rows and the announcer all go through it — never interpolate `mods.*Mult` raw into a template string (test-enforced).
- Bump `?v=` cache-bust strings in `index.html` whenever any root asset changes.
- Overlays shown/hidden via the `hidden` attribute must never have an author CSS `display:` rule win over it — `styles.css` carries a global `[hidden] { display: none !important; }` for this (a missing copy once left the PAUSED screen stuck over every fight). Do not remove it.
- Version stamp in the same commit: `BUILD` const + `UPDATE_LOG` entry in `app.js`, `BUILD <ver> // <TAG>` footer in `index.html`. Current: BUILD 2026.11.15 // ROUND ANNOUNCER, bust `20261110k`.
- Keep `README.md` and `AGENTS.md` current in the same commit as the change.
- Save format is `cbp-save-v2` (ranked: SR, peak, season, cosmetics, operatives). Changing its shape needs a migration, not a silent break — `migrateSave()` converts `cbp-save-v1` stars/arenas to starting SR (100 per arena + 20 per star). Operatives unlock by SR inside `applyRankedResult` (GHOST 500, BULWARK 1100); seasons end when the owner bumps `SEASON` in `engine.js`, awarding the peak-rank badge, never resetting SR.
- Deploy is GitHub Pages from `main` root. After every push: poll the Pages URL and grep the BUILD footer before declaring the deploy live.
